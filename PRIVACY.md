# Privacy

Nightmare 404 runs locally in the browser. The game does not include analytics, advertising, trackers, accounts or a backend.

Progress, settings and archive state are stored in the browser using `localStorage`. Exported backup files are created on the device and are not uploaded by the app. Clearing site data removes local progress unless a backup has been saved separately.

The PWA Service Worker caches only same-origin game resources required for offline use.
