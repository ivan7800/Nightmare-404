# Créditos de assets — Nightmare 404 v3.2.0

Esta edición prioriza recursos originales y locales. La aplicación no carga audio, imágenes ni scripts desde terceros en tiempo de ejecución.

## Audio CC0 de Kenney

Se incluyen dos sonidos de interfaz procedentes de **Kenney Interface Sounds**:

- `assets/audio/kenney-click-002.ogg` — derivado de `click_002.wav`.
- `assets/audio/kenney-click-005.ogg` — derivado de `click_005.wav`.

Origen oficial: `https://kenney.nl/assets/interface-sounds`

Mirror de código usado para obtener los ficheros WAV: `https://github.com/Calinou/kenney-interface-sounds`

Licencia: **Creative Commons CC0 1.0 Universal**. Kenney indica que sus assets pueden utilizarse incluso en proyectos comerciales y que la atribución no es obligatoria. Se mantiene este crédito voluntario por trazabilidad.

Licencia CC0: `https://creativecommons.org/publicdomain/zero/1.0/`

Los WAV originales se convirtieron localmente a OGG/Vorbis para reducir peso. No se alteró su intención funcional.
